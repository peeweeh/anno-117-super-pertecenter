## 📋 Version Guidelines

### Version Format: MAJOR.MINOR.PATCH

- **MAJOR**: Breaking changes, complete redesigns, scope changes
- **MINOR**: New features, ship additions, significant balance changes
- **PATCH**: Bug fixes, documentation updates, minor tweaks

### Change Categories

- 🚢 **Added**: New features or ship modifications
- ⚡ **Changed**: Alterations to existing functionality
- ⚠️ **Deprecated**: Features marked for removal
- ❌ **Removed**: Deleted features or modifications
- 🐛 **Fixed**: Bug fixes and error corrections
- 🔒 **Security**: Security-related changes (rare for mods)
- ⚖️ **Balance**: Stat adjustments for gameplay balance
